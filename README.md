# Saad Ali — Portfolio

A recruiter-focused personal portfolio for Saad Ali, a final-year Computer Science student and Machine Learning Intern based in Lahore, Pakistan.

## Highlights

- Modern responsive portfolio with accessible, motion-aware interactions
- Selected AI/ML, database, algorithm and software engineering case studies
- Education, internship experience, certifications and technical toolkit
- Purpose-built Open Graph card for professional link sharing
- Pre-exported static bundle for fast Vercel delivery

## Local development

```bash
pnpm install
pnpm dev
```

The main source lives in `app/`. The `static-site/` directory is the production-ready Vercel output configured by `vercel.json`.
